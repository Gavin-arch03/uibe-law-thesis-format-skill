# 法学硕士学位论文的结构模式与标题拟定

基于 30 篇对外经贸大学法学院硕士学位论文的实测归纳（章骨架由 `pdf_probe.py outline` 自动提取）。

## 一、三种主流逻辑链

### 模式 A · 通说型（最常用）

```
导论 → 概述界定 → 问题困境 →（成因分析）→ 域外借鉴 → 完善建议 → 结论
```

要点：第 N 章的**问题清单**与第 N+2 章的**对策清单一一咬合**——问题几条，对策就几条，不缺不多。

实例《论电子商务背景下消费者权益的民法保护》（7 章）：

```
第1章 导论（背景意义 / 国内外文献综述 / 研究内容与方法 / 创新点）
第2章 电子商务中消费者权益保护的基本理论（概念 / 特征 / 类型 / 必要性）
第3章 我国…存在的问题（知情权 / 安全保障权 / 退换货权 / 选择权 / 司法赔偿 / 格式合同）
第4章 …存在问题的原因分析（信息不匹配 / 虚假广告 / 技术不成熟 / 准入机制 / 监管缺失 / 立法滞后）
第5章 国外消费者权益保护制度的分析（经合组织 / 欧盟 / 美国）
第6章 我国…制度的改进与完善
第7章 结论
```

注意第 3 章与第 4 章是**镜像结构**：3.1↔4.1、3.2↔4.2……"问题清单 → 原因清单"逐条对应，是最稳的论证骨架。

### 模式 B · 问题导向型

适合民法典条文、司法解释类"规范已存在但适用混乱"的选题。不写"概述/基础理论"，直接摆司法困境，后续每章解决一个技术争点。

```
导论 → 司法实践问题 → 争点拆解（认定标准 / 权利行使 / 救济路径）→ 结论
```

实例《第三人欺诈导致的合同撤销问题研究》（6 章）：第2章 司法实践中存在的问题 → 第3章 第三人的认定标准 → 第4章 撤销权的行使 → 第5章 对受损害一方的权利救济 → 第6章 结论。

### 模式 C · 实证型

需裁判文书批量检索或数据统计时使用，通常页数最多。

```
绪论 → 制度介绍 → 制度背景与现状 → 研究假设与实证设计 → 实证回归结果 → 结论
```

实例《股票司法拍卖对股价的影响研究》（6 章，81 页，唯一带"研究假设"章的样本）。

## 二、官方目录范本

《医疗类PPP项目的法律监管研究》（法学院格式示例原样）：

```
第1章 导论
  1.1 选题的背景及理论意义
  1.2 文献综述
  1.3 研究内容与方法
第2章 医疗类PPP项目的界定及其涉及的法律关系
  2.1 医疗类PPP项目的界定
  2.2 医疗类PPP项目涉及的法律关系
第3章 我国医疗类PPP项目法律监管的现状与问题
  3.1 我国医疗类PPP项目法律监管的现状
  3.2 我国医疗类PPP项目法律监管存在的主要问题
    3.2.1 监管主体定位不明确
    3.2.2 缺乏直接针对医疗类PPP项目的监管规则
    3.2.3 事前监管、事中监管、事后监管均存在不足
    3.2.4 法律监管中的公众参与严重不足
第4章 医疗类PPP项目法律监管的域外经验及其借鉴可行性分析
  4.1 医疗类PPP项目法律监管的域外经验总结
  4.2 医疗类PPP项目法律监管域外经验的借鉴可行性分析
第5章 完善我国医疗类PPP项目法律监管的对策
  5.1 以"精准监管"和"全流程监管"作为…的基本理念
  5.2 强化医疗类PPP项目监管立法的针对性
  5.3 构建医疗类PPP项目的专门监管机构和绩效评估机制
  5.4 加强医疗类PPP项目的全流程法律监管
  5.5 促进医疗类PPP项目的公众参与
第6章 结论
参考文献 / 致谢 / 个人简历在校期间发表的学术论文及研究成果
```

四条可复用规则：

1. 第 3 章四个问题 ↔ 第 5 章四个对策（5.2–5.5），一一咬合
2. 第 4 章是"经验总结 + 借鉴可行性"两节，**不是国别罗列**
3. 第 2 章只写"界定 + 法律关系"，控制篇幅，重心放在问题与对策
4. 第 5 章标题都较长——"标题不能太长"是指不能只堆名词，内容充实时写实、写长是允许的

## 三、标题拟定的官方反例与正例

| ❌ 不合格 | ✅ 改成 |
|---|---|
| 第5章 对策与建议 | 第5章 完善我国医疗类PPP监管的对策与建议 |
| 2.2 问题 | 2.2 我国医疗类PPP法律监管存在的问题 |
| 2.2.1 主体 | 2.2.1 监管主体不明确 |
| 2.2.2 理念 | 2.2.2 监管理念不科学 |
| 4.1 域外经验 | 4.1 医疗类PPP法律监管的域外经验 |
| 4.1.1 美国 | 4.1.1 以美国为代表的集权型监管模式 |
| 4.1.2 英国 | 4.1.2 以英国为代表的分散型监管模式 |

规律：反例通病是**只有名词、没有限定语与判断**（"美国"不知道写美国的什么）；正例结构是「**限定语 + 对象 + 判断/属性**」。

## 四、层级与排版铁律

```
第2章（一级，必用）
  2.1（二级，必用）
    2.1.1（三级，可用可不用）
      （一）
        1.
        （1）
```

- **禁止四级编号**（2.2.2.1），目录也不能出现
- 除最后一章「结论」外，各章一级、二级标题必须有
- 不是每个二级标题下都要三级标题；内容少就别硬拆
- **一页不能出现好几个二/三级标题**（说明好几节挤在一页，属不规范）
- 各级标题不加标点；章与章另起一页
- 各章字数不能畸轻畸重

## 五、样本统计参考

| 指标 | 中位 | 说明 |
|---|---|---|
| 章数 | 6 | 5–6 章占 69%（6 章 12 篇、5 章 8 篇、7 章 3–4 篇） |
| 页数 | 47–50 | 38–81 |
| 中文字数 | 31,617 | 22,679–61,166（规范下限 2.5 万，全部达标） |
| 摘要字数 | 670 | 332–1,164 |
| 「参见」次数 | 44 | 反映脚注引用强度 |
| 图表 | 极少 | 30 篇仅 2 篇有分章编号图表 |

**结论带章号**：26–29/30 篇写「第N章 结论」——学院口径就是加章号。

## 六、解析局限（需知）

- 知网裁边版 PDF 的目录常被拆成碎行 + 全角数字，解析器已做归一化，但仍有约 10% 的样本只能识别部分章
- 若 `analyze_collection.py` 报出某篇 "1 章"，说明目录解析失败，需人工看该篇目录页，不要直接采信章数
- 章节标题中间可能含 OCR 错字（如"研宄""虡假"），不影响结构判断，但引用书名时须核对原书
