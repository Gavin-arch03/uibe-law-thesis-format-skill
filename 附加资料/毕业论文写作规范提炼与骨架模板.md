## 3. 结构编排铁律（法学院示例"注意事项"原文提炼）

这部分是示例文档里最重要的软规则，比字号更影响评审印象。

### 3.1 标题层级

```
第2章（一级标题，必用）
  2.1（二级标题，必用）
    2.1.1（三级标题，可用可不用）
      （一）
        1.
        （1）
```

- **不许出现四级编号**（`2.2.2.1`、`3.3.3.1` 这类一律禁止），目录里也不能有。三级下面还要分，就用「（一）」「1.」「（1）」。
- **除最后一章"结论"外**，各章的一级、二级标题都必须有。
- **不是每个二级标题下都要有三级标题**。内容少的节就别硬拆。

### 3.2 一页不能挤多个标题（最容易犯的错）

> "使用三级标题的，切记不能**一页出现好几个三级标题**，那就意味着好几节内容都在一页纸上，这是非常不规范的……**决不能出现某些二级、三级标题内容太少，一页纸上出现好几个二级标题或者三级标题的情况**。二级标题之间、三级标题之间，都是并列关系，一定要注意内容的轻重分布应当合理，不能失衡。"

**自检**：打开你的论文，随便翻几页——如果一页里出现 2 个以上二/三级标题，立刻合并或改写。

### 3.3 标题必须"不太短，也不太长"

示例给的反例（这些写法不严谨）：

| ❌ 不合格 | ✅ 改成 |
|---|---|
| 第5章 对策与建议 | 第5章 完善我国医疗类PPP监管的对策与建议 |
| 2.2 问题 | 2.2 我国医疗类PPP法律监管存在的问题 |
| 2.2.1 主体 | 2.2.1 监管主体不明确 |
| 2.2.2 理念 | 2.2.2 监管理念不科学 |
| 4.1 域外经验 | 4.1 医疗类PPP法律监管的域外经验 |
| 4.1.1 美国 | 4.1.1 以美国为代表的集权型监管模式 |
| 4.1.2 英国 | 4.1.2 以英国为代表的分散型监管模式 |

**规律**：标题要能独立表达一个判断或一个具体对象。
- 反例的通病是**只有名词，没有限定语**——"美国"不知道写美国的什么
- 正例的结构是「**限定语 + 对象 + 判断/属性**」

### 3.4 其他硬规矩

| 规则 | 说明 |
|---|---|
| 章与章另起一页 | "不要在一页纸上出现两章" |
| 各级标题不加标点 | "除非特别需要，各级标题当中都不要使用标点符号" |
| 字数分布 | "务必慎重分布各个章节的内容即字数，**不能畸轻畸重**"；国内法论文的对策建议部分应是重点；国际法论文应涉及中国如何应对 |
| 结论不设二级标题 | 示例结论章只有一段连续论述 |

## 5. 逻辑骨架

### 三种主流模式

**A｜通说型**（12/29，最常用）
`导论 → 概述界定 → 问题困境 → 域外借鉴 → 完善建议 → 结论`

**B｜问题导向型**（适合民法典条文、司法解释类×适用混乱的选题）
`导论 → 司法实践问题 → 争点逐个拆解 → 权利行使／救济 → 结论`

**C｜实证型**（需裁判文书批量检索或数据统计）
`绪论 → 制度现状 → 研究假设与设计 → 实证结果 → 结论`

**可提炼的四条规则**：

1. **第3章的问题清单 = 第5章的对策清单，一一咬合**。3.2 四个问题（主体/规则/流程/参与）↔ 5.2–5.5 四个对策（立法/机构/流程/参与）。**问题几条，对策就几条，不缺不多。**
2. **第4章是"经验 + 可行性"两节，不是国别罗列**。4.1 总结经验（不写"美国怎样""英国怎样"），4.2 论证能否移植。示例的标题拟定注意事项里专门批评了"4.1.1 美国"这种写法。
3. **第2章只写"界定 + 法律关系"两节，控制篇幅**。概念章不要写太长，重点在问题与对策。

## 6. 脚注体例（法学院 2020，定论）

### 6.1 五条通用规则

| 规则 | 具体要求 |
|---|---|
| 字体行距 | 中文脚注**宋体、小五、固定值 12 磅**；英文脚注见 §6.3 |
| 符号与内容 | 脚注符号与脚注内容之间**空一格** |
| 位置 | **标点符号在前，脚注符号在后**；尽量不要在一句话（无标点）中间插脚注；**尽量不要在各级标题中插脚注** |
| 编号 | **全文连续排序，样式为 1、2、3**（不是 ①②③，不按页重编） |
| 引用词 | 直接引用原文（用"……"）**不加"参见"**；非直接引用**加"参见"**；非引用原始资料注明"**转引自**" |
| 重复引用 | **直接重复引用即可，不使用"前引……"**；但页码不同务必改对 |

示例（第1章导论正文页脚注）：

```
1 参见贾康、孙洁：《公私伙伴关系（PPP）的概念、起源、特征与功能》，载《财政研究》2009 年第10 期，第2 页。
2 该规范明确指出：要放宽市场准入……这标志着民营资本可以全面进入基础设施和公用事业领域。
3 包括但不限于：《国务院办公厅关于全面推开县级公立医院综合改革的实施意见》……
```

> 注意脚注 2 是**解释性说明**（无文献来源），不加"参见"——这正是脚注与参考文献的分工：脚注可解释，可征引；参考文献只列征引文献。

### 6.2 中文脚注九类格式

| # | 类型 | 格式 | 实例 |
|---|---|---|---|

| 类型 | 格式 | 实例 |

| 著作 | 作者全大写, 书名全大写 引用页 (编者 eds., 版次 年份). | FRANCIS A. CAREY, ORGANIC CHEMISTRY 310 (Kent A. Peterson et al. eds., 6th ed. 2006). |

**格式细节**（法学院特别提示）：
- 书名的作者与题名**全部字母大写**，**首字母字号大一号**（常见 9 号），其余字母小一号（8 号）——即小型大写字母（small caps）效果
- 期刊**文章标题用斜体**；期刊名全大写、首字母大
- 简写：`Id.` 指紧邻的前一脚注；`Supra` 指前面非紧邻的某脚注；`Infra` 指稍后部分。三者**均用斜体**；页码不同时加 `at 页数`
- 缩写按 Bluebook 规则：Academy→Acad.；Court of Appeal→C.A.；Pennsylvania→Pa.；Journal of Law and Commerce→J.L. & COM.

### 6.4 Zotero 怎么配

你库里现在装的是 `china-national-standard-gb-t-7714-2015-note.csl` —— **这个用不上**。法学院体例不是任何现成 CSL 能对上的（它混合了《法学引注手册》中文格式 + Bluebook 英文格式）。

可行方案：

| 方案 | 做法 | 适合 |
|---|---|---|
| A（推荐） | Word 里用 Zotero 插件的「**经典/脚注样式**」插入，选定 `China Law` 类样式后**逐条手工微调**成法学院格式 | 条目不多、要求严格 |
| B | 用 Zotero 的「**快速复制**」导出为纯文本，再手工整理成脚注 | 只想借 Zotero 管元数据 |
| C | 关掉 Zotero 插件，脚注全部手打（多数法学论文的实际做法） | 追求格式绝对可控 |

> 说明：法学脚注体例的字段要求（必须有页码、不出现"卷"、网络资源不加网站名）与 CSL 的字段映射不一致，**全自动生成不现实**。Zotero 在这里更适合当"资料库 + 元数据源"，排版仍要手工。

### 7.3 两份法学院文件在序号括号与排序上的差异 → 已按"以学院体例为准"定死

| 项目 | 《脚注及参考文献体例》（2020-01-01 施行） | 《硕士学位论文格式示例》（2020.01） | ✅ 采用 |
|---|---|---|---|
| 序号括号 | **【1】** 中文方头括号 | [1] 英文方括号 | **【1】中文方头括号** |
| 类内排序 | **时间降序**（由新到旧） | 时间升序（2011 → 2014） | **时间降序** |

**裁决理由**：两份都是法学院文件，但**分工不同**——《脚注及参考文献体例》是专管"体例"的文件，条文表述明确"排序用【1】……连续排列""每一种类的参考文献，按照时间降序排列"，且落款 2020-01-01 写明"请各位同学在撰写学位论文时严格执行"；而《格式示例》首页自述"**本示例主要解决基本格式问题**"，它管的是字体字号版面，不管体例。

→ **体例问题归体例文件，故用【】+ 时间降序。**

⚠️ 唯一底线：**全文绝不能【】和 [] 混用，也不能一类升序一类降序。**

## 9. 摘要怎么写（法学院示例要求）

| 项目 | 要求 |
|---|---|
| 长度 | 中文摘要"加上关键词，**写满一页纸为宜**"；学校规范：硕士 500–1000 字 |
| 字体行距 | 宋体小四，行距 20（与正文同） |
| 结构 | 分**两段或三段**写 |
| ❌ 禁止 | **记账式摘要**——不能出现"本文分为五章，第一章……第二章……" |
| ✅ 应当 | 浓缩全文：明确指出**分析的问题**与**提出的观点与建议** |
| 关键词 | 3–5 个，用**逗号「，」**分隔（学院示例与 30 篇样本均用逗号；学校规范的"中文分号"不采用） |
| 英文摘要 | 每段开头**不空格、顶格写**，段与段之间空一行 |
| 英文关键词 | `Keywords:` 开头，词组间用英文分号 `;`，单词首字母大写 |
| 禁区 | 摘要中**不得出现图片、图表、表格或任何插图材料** |
